# 初二错题本 AI 录入系统 - 部署手册

> 本系统让孩子拍错题发到飞书，AI 自动识别题目并录入飞书多维表格，全程无需手动操作。

---

## 系统架构

```
孩子拍错题
    ↓
发送图片到飞书机器人
    ↓
OpenClaw（Mac 本地）自动接收
    ↓
AI 图像识别（多模态大模型）提取题目内容
    ↓
调用飞书 API 上传图片 + 写入多维表格记录
    ↓
飞书表格自动更新（含题目、答案、知识点、原图）
```

**运行环境：** Mac（OpenClaw Gateway）、飞书多维表格
**AI 模型：** 多模态大模型（图片理解能力）
**自动化程度：** 发图片 + 说"录入" → 全自动

---

## 部署步骤

### 第一步：安装 OpenClaw

参考官方文档：https://docs.openclaw.ai

Mac 安装：
```bash
brew install openclaw
openclaw wizard
```

### 第二步：配置飞书频道

```bash
openclaw channel add feishu
```

需要提供：
- 飞书企业自建应用的 `App ID` 和 `App Secret`
- 在飞书开放平台创建应用，配置机器人能力

参考：https://docs.openclaw.ai/channels/feishu

### 第三步：创建飞书多维表格

**手动创建（只需一次）：**

1. 打开飞书 → 新建多维表格，命名为「初二错题本」
2. 创建数据表，命名为「错题记录」
3. 按以下结构设置字段：

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 学科 | 单选 | 语文/数学/英语/物理/历史/道法/地理/生物 |
| 题目内容 | 文本 | 识别出的题目文字 |
| 正确答案 | 文本 | 正确答案/解题思路 |
| 错因分析 | 文本 | AI 自动分析或手动补充 |
| 知识点 | 多选 | 按学科设置常见知识点 |
| 难度 | 单选 | ⭐ / ⭐⭐ / ⭐⭐⭐ |
| 录入时间 | 日期 | 自动记录 |
| 备注 | 文本 | 自由补充 |
| 原图 | 附件 | 题目原图 |

4. 记录多维表格的 `app_token`（从 URL 获取）

### 第四步：获取飞书凭证（供 API 调用用）

应用需要在飞书开放平台开通以下权限：
- `drive:file:upload`
- `bitable:app:readonly`
- `bitable:app:write`

## 关键技术细节

### 1. 图片上传（最容易踩坑的地方）

飞书有两套文件存储系统，**必须使用 Bitable 专用 API**：

**API Endpoint：**
```
POST https://open.feishu.cn/open-apis/drive/v1/files/upload_all
```

**容易搞错的点：**
- ❌ 错误：`media/upload_all`（不存在）
- ✅ 正确：`files/upload_all`
- ❌ 错误：`parent_type=bitable_file`（图片会 404）
- ✅ 正确：`parent_type=bitable_image`（图片可预览）

**extra 参数（关键）：**
```json
{
  "bitablePerm": {
    "tableId": "table_id"
  }
}
```

### 2. 用户认证 Token 获取

用户访问令牌存在 macOS Keychain：

```
Service: openclaw-feishu-uat
Account: {appId}:{userOpenId}
```

Keychain 里存的是完整 JSON，需要提取其中的 `accessToken` 字段：

```bash
FULL_TOKEN=$(security find-generic-password -s "openclaw-feishu-uat" \
  -a "cli_a93534f5edb85bd3:ou_2ad19bb3863e71e2d0eff5cc4aeedd83" -w)
ACCESS_TOKEN=$(echo "$FULL_TOKEN" | python3 -c \
  "import sys,json; d=json.load(sys.stdin); print(d.get('accessToken',''))")
```

### 3. 文件路径限制

飞书 bitable 上传接口要求文件必须在系统临时目录：

```bash
# macOS 临时目录
cp /path/to/image.jpg /var/folders/8r/0b88l2d52ys5974p0fms08mr0000gn/T/image.jpg
```

### 4. 写入记录

上传成功后，用返回的 `file_token` 写入附件字段：

```json
{
  "fields": {
    "原图": [{ "file_token": "返回的token" }]
  }
}
```

## 故障排查

### 图片上传返回 404

**原因：** 用了云盘 API 而不是 bitable 专用 API

**解决：**
1. 确认 endpoint 是 `drive/v1/files/upload_all`（不是 `media/upload_all`）
2. 确认 `parent_type` 是 `bitable_image`（不是 `bitable_file`）
3. 确认 `extra` 参数包含 `bitablePerm.tableId`

### 附件字段写入失败（WrongRequestBody）

**原因：** file_token 不是 bitable 专用格式

**解决：** 确认是用 bitable_upload API 上传的，而不是云盘 uploadAll API

### AI 识别内容不准确

**原因：** 图片不清晰或题目超出模型能力范围

**解决：**
1. 确保图片清晰，光线充足
2. 题目文字尽量完整入镜
3. 可以手动补充/修正识别结果

### 工具无法调用

**原因：** OpenClaw Gateway 重启后工具注册可能延迟

**解决：**
- 等待几秒后重试
- 或执行 `openclaw gateway restart`
