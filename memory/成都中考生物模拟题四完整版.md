**题目47：探究实验（10分）**

实验步骤：
- ①号试管：馒头碎屑 + 2mL唾液，振荡后37℃水浴10分钟 → 滴加碘液2滴
- ②号试管：馒头碎屑 + 2mL清水，振荡后37℃水浴10分钟 → 滴加碘液2滴
- ③号试管：馒头碎屑 + 2mL唾液，振荡后0℃水浴10分钟 → 滴加碘液2滴

实验结果：
- ①号试管：不变蓝
- ②号试管：变蓝
- ③号试管：部分变蓝

**（1）（2分）** ①号和②号试管形成对照实验，变量是__________。

**答案：** 淀粉没有被分解
