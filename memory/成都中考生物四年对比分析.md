## 四、四年变化趋势总结

### 越来越强（必须掌握）
1. **图文转换能力**：过程图、装置图、坐标曲线图出现率↑↑
2. **实验设计思维**："不能验证什么"类的逆向思维题增加
3. **知识综合**：光合+呼吸+蒸腾三合一综合题
4. **联系生活**：成都本地元素（熊猫基地、草莓、蜀锦）

### 逐渐弱化
1. 单纯记忆题（直接背答案）
2. 偏难怪题型（难度稳定，基础题比重反而↑）

## 五、四年选择题高频丢分点

| 易错点 | 年份出现 | 错误原因 |
|--------|---------|---------|
| 植物细胞有叶绿体 | 2021,2,3,4 | 记成动物细胞也有 |
| 光合作用需要光 | 2021,2,3,4 | 与呼吸作用混淆 |
| 反射弧完整性 | 2022,3,4 | 不知道必须五部分全 |
| 生男生女概率50% | 2021,2,3,4 | 误以为100%或0% |
| 原尿vs尿液区别 | 2022,3,4 | 葡萄糖被重吸收 |
| 扦插是营养生殖 | 2021,2,3,4 | 混淆有性/无性 |
| 自然选择方向 | 2021,2,3,4 | 误以为是"用进废退" |

## 六、2024年考前预测

### 大概率再考
- 光合作用综合（过程图+物质推断）
- 心脏结构+血液循环
- 尿液形成（蛋白质/葡萄糖重吸收）
- 遗传图谱（显隐性判断）
- 生态系统食物网

### 可能轮换考
- 显微镜操作（注意：目镜×物镜放大倍数）
- 呼吸运动（膈肌收缩→胸腔扩大）
- 花的结构（子房→果实）
- 昆虫发育（完全变态/不完全变态）

## 七、兮兮冲刺复习建议

### 4月24日实验操作考试
熟练操作：
1. 显微镜对光、低倍转高倍
2. 临时装片制作（洋葱/口腔上皮）
3. 气泡与细胞区分
4. 常见材料器具认别

### 选择题冲刺（每天3-5题）
优先级：
1. 🔴 光合/呼吸综合（装置图）
2. 🔴 心脏结构+血液循环方向
3. 🔴 遗传概率（50%永远是50%）
4. 🟠 反射弧完整性
5. 🟠 生态系统食物链/能量传递

### 非选择题重点
- 光合作用：物质来源和去路
- 心脏：左心室最厚（泵血到全身）
- 肾脏：葡萄糖全被重吸收，蛋白质不能滤过
- 遗传：显隐性判断口诀（无中生有是隐性）
