## 三、三年稳定题型（非选择题）

### 1. 光合作用/呼吸作用综合题
- **2022** 大豆叶片结构 + 光合作用过程图
- **2023** 光合作用装置实验（甲乙丙检测淀粉）
- **2024** 光合作用过程图（①②③物质推断）

### 2. 花的结构/植物生殖
- **2022** 桃花雌蕊结构→发育成种子
- **2023** 草莓匍茎→营养繁殖
- **2024** 扦插→无性生殖判断

### 3. 血液循环路径
- **2022** 手臂抽血（青筋→静脉）+ 心脏结构
- **2023** 血液循环示意图 + 心脏四腔
- **2024** 血液循环（推测）

### 4. 遗传图谱/判断
- **2022** 白色家兔毛色（基因+环境） + 生男生女概率
- **2023** 果蝇灰身/黑身遗传实验
- **2024** 遗传图推理（推测）

### 5. 生态系统/食物网
- **2022** 浣花溪公园食物网 + 生态瓶制作
- **2023** 生态系统自动调节能力
- **2024** 生态系统（推测）

## 四、三年变化趋势总结

### 越来越强的趋势
1. **图文转换能力**：装置图、模式图、坐标曲线图出现频率↑
2. **实验设计思维**：不仅考结论，还考"为什么这样设计"
3. **知识综合能力**：一道题跨2-3个知识点（光合+呼吸+蒸腾综合）
4. **联系社会热点**：新冠疫苗、急救知识、食品安全↑

### 逐渐减少的
1. **单纯记忆题**：直接背答案的题目↓
2. **孤立知识点**：一个题一个知识点的形式↓
3. **偏难怪题型**：难度没有明显上升，反而更注重基础

## 五、必考题型分类清单

### 🔴 选择题高频丢分TOP5
1. 细胞结构（动/植物对比）—— 粗心容易选错
2. 反射弧/条件反射 —— 反射必须有完整弧
3. 蒸腾作用 vs 呼吸作用 —— 重量变化的原因
4. 光合作用/呼吸作用物质变化 —— CO2/O2/有机物方向
5. 遗传概率计算 —— 50%不是100%

### 🟠 非选择题高频丢分TOP5
1. 光合作用综合图 —— 物质来源和去路
2. 心脏结构 + 血液循环方向 —— 瓣膜方向判断
3. 尿液形成各段浓度变化 —— 葡萄糖被重吸收
4. 遗传图谱分析 —— 显隐性判断+基因型推导
5. 生态系统能量流动 —— 传递效率10-20%
