## 三、非选择题六年重点题型

### 🔴 光合作用综合（2021-2024四年全勤）

| 年份 | 题型 | 图/题特征 |
|------|------|----------|
| 2021 | 叶片结构+光合 | ①-④结构标注 |
| 2022 | 大豆叶片+光合 | 甲乙过程图 |
| 2023 | 装置实验（甲乙丙） | 氢氧化钠吸收CO₂ |
| 2024 | 过程图 | ①②③物质推断 |

**答题套路（背熟）：**
- 叶绿体是光合作用的场所
- CO₂+H₂O→有机物+O₂
- 光是条件，叶绿体是场所，原料CO₂和H₂O

### 🔴 生态系统/食物网（六年全勤）

| 年份 | 题型 |
|------|------|
| 2019 | 农田生态系统，食物链书写 |
| 2020 | 能量流动特点 |
| 2021 | 生态瓶制作 |
| 2022 | 食物网+自动调节 |
| 2023 | 生态系统结构 |
| 2024 | 食物网（推测） |

**答题套路（背熟）：**
- 食物链：生产者→消费者，箭头指向
- 能量传递：10-20%，逐级递减
- 分解者：将有机物→无机物

### 🔴 遗传图谱（六年全勤）

| 年份 | 题型 |
|------|------|
| 2019 | 显隐性判断+A/a基因书写 |
| 2020 | 人类染色体+性别决定 |
| 2021 | 家兔毛色（基因+环境） |
| 2022 | 生男生女概率+遗传病 |
| 2023 | 果蝇杂交实验 |
| 2024 | 遗传图推理（推测） |

**答题套路（背熟）：**
- 显隐性判断："无中生有是隐性"
- 概率：AA:Aa:aa比，50%是常错
- 染色体：XY是男性，XX是女性

## 四、六年变化趋势总结

### 2019-2024命题演变

| 阶段 | 特征 | 典型题 |
|------|------|--------|
| 2019-2020 | 基础知识为主，记忆题多 | 关节结构、研究方法、动物分类 |
| 2021-2022 | 图文题增加，综合性↑ | 光合作用综合图、遗传图谱 |
| 2023-2024 | 实验设计思维、逆向思维↑ | "不能验证什么"、装置实验 |

### 越来越强
1. **图文转换能力** ↑↑
2. **实验设计逻辑** ↑↑
3. **成都本地元素** ↑（熊猫基地、草莓、蜀锦）
4. **知识综合** ↑（光合+呼吸+蒸腾三合一）

### 越来越弱
1. 单纯记忆题 ↓
2. 偏难怪题 ↓
3. 超纲内容 ↓

## 六、兮兮冲刺复习建议

### 优先级1（必须全对）
1. 光合作用方程式+叶绿体是场所
2. 心脏四腔+瓣膜方向（体循环/肺循环）
3. 遗传50%概率
4. 尿液形成（蛋白质/葡萄糖）
5. 生态系统能量传递

### 优先级2（尽量全对）
1. 反射弧五部分（感受器→传入神经→神经中枢→传出神经→效应器）
2. 扦插=营养生殖
3. 自然选择："适者生存"，不是"用进废退"

### 优先级3（基础分）
1. 显微镜放大倍数=目镜×物镜
2. 细菌无成形细胞核，真菌有
3. 动物分类特征（鸟类→羽毛、哺乳类→毛发/胎生）

### 4月24日实验操作
- 显微镜对光→低倍转高倍
- 临时装片制作
- 气泡与细胞区分

## 七、六年选择题错题本（高频错）

1. ❌ "关节结构" → 记住：关节囊+关节腔+关节软骨
2. ❌ "研究方法" → 野外观察=观察法，不是实验法
3. ❌ "生产者" → 草是生产者，兔子是消费者
4. ❌ "营养生殖" → 扦插/嫁接/分株都是
5. ❌ "表现型" → 基因+环境共同决定
6. ❌ "自然选择" → 适者生存，不是用进废退
7. ❌ "生男生女" → 永远是50%
