**题目39：探究实验（10分）**

某生物兴趣小组探究"馒头在口腔中的变化"：

实验步骤：
- ①号试管：加入馒头碎屑 + 2mL唾液，37℃水浴10分钟 → 加碘液2滴
- ②号试管：加入馒头碎屑 + 2mL清水，37℃水浴10分钟 → 加碘液2滴
- ③号试管：加入馒头碎屑 + 2mL唾液，0℃水浴10分钟 → 加碘液2滴

实验结果：
- ①号试管：不变蓝
- ②号试管：变蓝
- ③号试管：部分变蓝

请根据实验回答问题：

**（1）（2分）** 本实验探究的问题是：__________对淀粉消化有影响吗？变量分别是__________。

**答案：** 唾液（或温度）；①有唾液（37℃）、②无唾液、③有唾液（0℃）

---

**（2）（2分）** ①号试管不变蓝，说明淀粉被__________消化了。

**答案：** 唾液淀粉酶

---

**（3）（2分）** ②号试管变蓝，说明淀粉__________（填"被分解"或"没有被分解"）。

**答案：** 没有被分解

---

**（4）（2分）** 比较①③试管，说明__________会影响唾液淀粉酶的活性。

**答案：** 温度

---

**（5）（2分）** 本实验的结论是：唾液中的__________能消化淀粉，__________会影响其活性。

**答案：** 唾液淀粉酶；温度

**题目40：遗传分析（10分）**

某学校生物兴趣小组对人类遗传现象进行研究：

已知：人的单眼皮（a）为隐性，双眼皮（A）为显性。

调查结果：
- 调查家庭1：父亲双眼皮，母亲单眼皮，子女中有的单眼皮有的双眼皮
- 调查家庭2：父母都是双眼皮，子女也都是双眼皮
- 调查家庭3：父亲单眼皮（aa），母亲双眼皮（基因组成为Aa或AA），子女都是双眼皮

请分析回答：

**（1）（2分）** 双眼皮和单眼皮是一对__________性状。双眼皮为__________（填"显性"或"隐性"）性状。

**答案：** 相对；显

---

**（2）（2分）** 调查家庭1中，父亲基因组成为__________，母亲基因组成为__________。

**答案：** Aa；aa

**（3）（2分）** 调查家庭2中，父母基因组成可能是（填基因型）：__________。

**答案：** AA×AA、AA×Aa、Aa×Aa（任写一种即可）

---

**（4）（2分）** 调查家庭3中，如果母亲基因组成是Aa，父亲基因组成是aa，则他们所生子女双眼皮的概率是__________。

**答案：** 1/2或50%
