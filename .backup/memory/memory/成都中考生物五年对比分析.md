## 二、五年变化趋势（2020→2024）

### 📈 越来越强
1. **实验设计思维** — "不能验证什么""不属于的是"逆向题增加
2. **图文综合** — 装置图+过程图+坐标曲线图比重↑
3. **成都本地元素** — 熊猫、蜀锦、草莓基地、三星堆等

### 📉 逐渐弱化
1. **单纯记忆题** — "直接背出答案"的题↓
2. **偏难怪题** — 难度稳定，基础题比重反而↑
3. **过难知识** — 基因工程、克隆技术等advanced内容↓

## 三、五年选择题高频丢分点

| 易错题 | 年份 | 错误原因 |
|--------|------|---------|
| 动物运动方式（游泳） | 2020 | 审题不清 |
| 屈肘运动支点（关节） | 2020 | 误选肌肉/骨 |
| 本能行为（蜜蜂筑巢） | 2020 | 与学习行为混淆 |
| 细菌无细胞核 | 2020 | 记成"有核" |
| 光合作用需要光 | 2021-2024 | 与呼吸作用CO₂混淆 |
| 生男生女50% | 2020-2024 | 误以为100%/0% |
| 原尿vs尿液（蛋白质） | 2022-2024 | 葡萄糖重吸收不清楚 |
| 自然选择"用进废退" | 2020-2023 | 方向理解错误 |

## 六、兮兮考前最该抓的

### 优先级1（必须全对）
- 光合作用方程式+场所+条件
- 心脏四腔+瓣膜方向
- 尿液形成（全ir过滤/葡萄糖全重吸收）
- 遗传50%概率

### 优先级2（尽量全对）
- 反射弧五部分
- 生态系统能量传递（10-20%）
- 扦插=营养生殖

### 优先级3（基础分）
- 显微镜放大倍数
- 动物分类（鱼类/两栖类/哺乳类）
- 细菌结构（无成形细胞核）
