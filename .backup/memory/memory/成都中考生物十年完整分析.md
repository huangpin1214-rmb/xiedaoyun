| 2023 | 选择题 | 生态系统结构 |

**✅ 答题套路（背熟）：**
- 食物链：生产者→消费者，箭头指向捕食者
- 能量传递：10-20%递减，逐级减少
- 分解者：将有机物→无机物，供绿色植物再利用
- 生态系统稳定性：有一定的自动调节能力，但有限度

| 年份 | 考题 |
|------|------|
| 2016 | 呼吸系统结构 |
| 2017 | 青春期发育（不会厌唱） |
| 2018 | 膈肌收缩→胸腔扩大（吸气） |
| 2019 | 呼吸运动原理 |
| 2020 | 肺活量测定、膈肌收缩 |
| 2021 | 呼吸系统+人工呼吸 |
| 2022 | 膈肌和肋间外肌收缩，胸廓扩大 |
| 2023 | 呼吸运动（肋骨位置变化） |
| 2024 | 呼吸系统 |

**✅ 答题套路：**
- 吸气：膈肌收缩（下降）、肋间外肌收缩（外扩）→胸廓扩大→肺扩张→气体进入
- 呼气：膈肌舒张（上升）、肋间内肌收缩（内收）→胸廓缩小→肺收缩→气体排出
- 肺活量：尽力吸气后尽力呼气呼出气体量

### 🥉 六年稳定考点（2018-2024）

#### 9. 光合作用综合（四年出现：2021-2024）

**✅ 答题套路：**
- 原料：CO₂ + H₂O
- 产物：有机物 + O₂
- 场所：叶绿体
- 条件：光
- 公式：CO₂ + H₂O →（光能/叶绿体）→ 有机物 + O₂

---

#### 10. 心脏结构与血液循环（五年出现：2020-2024）

**✅ 答题套路：**
- 左心室壁最厚（泵血到全身）
- 右心室壁较厚（泵血到肺）
- 瓣膜方向决定血流方向（防止倒流）
- 体循环：左心室→主动脉→全身→右心房（动脉血→静脉血）
- 肺循环：右心室→肺动脉→肺→左心房（静脉血→动脉血）

---

#### 11. 尿液形成（三年出现：2022-2024）

**✅ 答题套路：**
- 肾小球：过滤作用（蛋白质不能过滤）
- 肾小管：重吸收作用（葡萄糖全部重吸收）
- 原尿：蛋白质很少，葡萄糖正常
- 尿液：蛋白质没有，葡萄糖没有（正常情况下）

## 六、兮兮冲刺复习建议

### 优先级1（必须全对）
1. 光合作用方程式 + 叶绿体是场所
2. 心脏四腔 + 瓣膜方向（体循环/肺循环）
3. 遗传50%概率（生男生女永远是50%）
4. 尿液形成（蛋白质/葡萄糖重吸收）
5. 生态系统能量传递（10-20%递减）

### 优先级2（尽量全对）
1. 反射弧五部分（感受器→传入神经→神经中枢→传出神经→效应器）
2. 扦插=营养生殖
3. 自然选择="适者生存"（不是用进废退）
4. 细菌无成形细胞核，真菌有

### 优先级3（基础分）
1. 显微镜放大倍数=目镜×物镜
2. 动物分类特征（鸟类→羽毛、哺乳类→胎生）
3. 完全变态：卵→幼虫→蛹→成虫

## 七、4月24日生物实验操作考试

### 操作必考
1. 显微镜对光 → 低倍转高倍
2. 临时装片制作（洋葱表皮/口腔上皮）
3. 气泡与细胞区分（气泡圆、有黑边、不规则）
4. 常见材料器具认别

### 注意事项
- 对光：转动转换器使低倍镜对准通光孔，调节光圈
- 观察：先低倍后高倍，缩小光圈
- 装片：材料要薄而透明，避免气泡
