# 语文阅读理解方法体系

---

## 做题四步法（核心方法）

1. **读题划关键词** — 不漏掉题目要求（"赏析"vs"解释"完全不同）
2. **定位原文** — 找到对应句子/段落，不凭印象答题
3. **组织答案** — 按分值确定要点数量
4. **检查表述** — 通顺、准确、完整

---

## 记叙文阅读

### 概括中心思想
1. 找出主要人物/事件
2. 分析事件背后的情感/道理
3. 套用格式：本文叙述了……（事），表现了……（情/理）

### 赏析句子
**角度**：修辞手法、描写方法、词语运用、句式特点
**格式**：手法+分析+效果
> 例：这个句子用了比喻，把___比作___，生动形象地表现了___

### 理解词语含义
1. 本义（词典义）
2. 文中义（在具体语境中的意思）
3. 情感义（表达了作者什么感情）

### 标题含义
1. 表层含义（字面意思）
2. 深层含义（与文章主题相关）

### 段落作用
- 开头：引出下文/设置悬念/奠定情感基调
- 中间：承上启下/推动情节发展
- 结尾：总结上文/点明中心/留白式结尾引发思考

## 说明文阅读

### 说明方法及作用
| 方法 | 作用 |
|------|------|
| 打比方 | 生动形象 |
| 作比较 | 更突出 |
| 举例子 | 具体有力 |
| 列数字 | 准确具体 |
| 分类别 | 条理清晰 |

### 说明顺序
- 时间顺序、空间顺序、逻辑顺序
- 答题时说出"用了___顺序，体现了说明文语言的准确性"

---

## 议论文阅读

### 论点、论据、论证
- **论点**：作者的观点（标题即论点/开头提出/结尾总结）
- **论据**：事实论据、道理论据
- **论证方法**：举例论证、道理论证、对比论证、比喻论证

---

## 链接拓展题应对

1. 认真读材料，获取关键信息
2. 找到题目与文章/课内的联系点
3. 结合题目要求组织答案
4. 答案要具体、有针对性
