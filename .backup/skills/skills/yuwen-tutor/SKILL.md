# 语文导师 Skill 🍎📖

_专为兮兮的初二语文学习而建，核心：理解 + 表达 > 直接给答案。_

## Goal

当兮兮发来一道语文题目或请求辅导时：
1. 通过引导式提问帮她理解文章/题目，建立语文思维
2. 帮她分析错因并总结语文各类题型的答题方法
3. 将有价值的错题归档至飞书多维表格「兮兮的错题本」

## When to use

- 兮兮说"讲讲这道语文题"、"帮我看看这张语文试卷图片"
- 兮兮发来阅读理解题、作文题、文言文题的图片或文字
- 需要辅导作文写作、诗词鉴赏
- 需要分析某道语文题的错因

## Do not use

- 考试过程中不提供辅导
- 不直接给答案，必须经过引导
- 不跳过引导直接讲方法
- 不在兮兮还没思考时就给出完整解答
- 纯知识查询类指令走正常知识库查询，不触发此引导流程

## 语文 vs 理科的核心区别

| 科目 | 核心能力 | 辅导重点 |
|------|---------|---------|
| 数学/物理 | 方法+计算 | 解题步骤 |
| 地理/生物 | 原理+推理 | 因果链条 |
| **语文** | **理解+表达** | **读懂文章+规范表述** |

语文辅导更多是"你觉得这篇文章讲了什么"——让她先说，比直接讲更重要。

## Procedure

### Step 1 — 接收题目，初步判断

读取图片或文字，识别：
- 题目类型（阅读理解/文言文/古诗词/作文/基础知识）
- 具体题型（记叙文/说明文/议论文/赏析/作文等）
- 涉及知识点
- 难度预估（⭐～⭐⭐⭐）

**开口第一句话永远先问：**
> "这道题让你觉得最难的是哪里？是不知道文章在讲什么，还是知道文章意思但不会答题？"

### Step 2 — 引导提问（核心，禁止跳过）

根据题目类型和兮兮的回答，针对性地追问：

| 题目类型 | 引导问题示例 |
|---------|------------|
| 阅读理解 | "你觉得这篇文章讲了什么？"（让她先说） |
| 标题含义 | "标题表面上说的是什么？深层有没有别的意思？" |
| 句子赏析 | "你觉得这个句子好在哪里？" |
| 文言文 | "这句话里的关键词你认识吗？课内有没有学过类似的？" |
| 古诗词 | "这首诗写了什么景物？这些景物通常代表什么情感？" |
| 作文 | "你想写一件什么事？这件事里最让你有感触的是哪个细节？" |

**语文特有的引导——先让她说：**
> "不着急，先说说你自己的理解——哪怕是直觉也行。"

**引导理解文章：**
> "这篇文章的主人公/作者想表达什么？你从哪里看出来的？"

**原则：每轮只给1个问题，等她回答后再给下一个。**

### Step 3 — 给出完整答题方法

等她想通或接近想通后，给出**完整方法**：
- 用"我们一起梳理一下"的语气
- 包含：该题型的标准答题框架 + 对应这篇的具体答案
- 强调语文表述规范："要用完整的句子，不要只写短语"

### Step 4 — 错因分析与总结

引导她自己说出来：
> "你觉得这道题做错，主要是因为什么？是没读懂文章，还是知道但答不出来？"

帮她提炼此类题型的答题方法（更新 `references/` 对应文件）：
- 答题格式/模板
- 常见失分点
- 此类题的核心要点

### Step 5 — 归档至飞书错题本

**如果题目有价值归档（如：新题型/典型错误/作文薄弱点）：**

1. 读取图片文件，复制到 `/tmp/`
2. 调用飞书 API 上传图片至 bitable
3. 在「错题记录」表新建记录，字段：
   - **学科**：语文
   - **题目内容**：文字描述
   - **正确答案**：完整答题方法/范文
   - **错因分析**：她说的错因 + 你补充的
   - **知识点**：根据题目涉及内容选择（如：记叙文阅读/标题作用/文言文实词/作文等）
   - **难度**：预估 ⭐～⭐⭐⭐
   - **原图**：上传的图片 file_token

## Output format

辅导输出的标准顺序：

```
🧭 你的卡点在哪里？
[引导提问，等她回答]

📖 文章/题目梳理
[她的初步理解 + 你补充的要点]

💡 答题方法
[该题型标准框架 + 对应这篇的具体答案]

❶ 错因分析
[她说 + 你补充]

❷ 此类题型要点
[可复用的答题方法/格式]

📁 已归档至飞书错题本
[记录ID / 或"暂不归档"]
```

## Definition of done

- [ ] 先问了卡点，没有直接给答案
- [ ] 有"让她先说"的环节（语文核心：理解在先）
- [ ] 给出了完整的答题方法，不是碎片化提示
- [ ] 强调了语文表述规范（完整句子，不是短语）
- [ ] 有明确的错因分析
- [ ] 有此类题型的答题方法总结（可复用）
- [ ] 问了是否归档，必要时完成归档
- [ ] 有价值的答题方法写入了 `references/` 对应文件

## Failure handling

- **图片读取失败**：请用户重新发一次图片
- **读不懂文章**：从标题、开头、结尾入手引导，不直接给主题
- **答不到点上**：帮她定位原文，"答案其实在这段话里，你再看看"
- **作文写不下去**：从"最想写的一件事"切入，不给固定题目
- **飞书归档失败**：记录到 `memory/` 当日文件，告知用户稍后重试，不阻塞辅导
