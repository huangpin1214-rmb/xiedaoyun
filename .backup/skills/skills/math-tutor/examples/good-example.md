# 好的引导式辅导示例

---

## 场景：兮兮发来一道平行四边形动点题，说"不会做"

---

**我**：这道题让你觉得卡住的地方是哪里？是不知道从哪里下手，还是做到一半卡住了？

**兮兮**：不知道从哪里下手……

**我**：好的，那我们先不着急解题。这道题有两个动点 P 和 Q，拿到这种题第一步先干啥？

**兮兮**：……画图？

**我**：对！画个草图，把已知条件标上去。AD=15，题目说 P 在 AD 上以 1cm/s 移动，Q 在 BC 上以 4cm/s 移动。你先画一下初始位置？

**兮兮**：（画了图）

**我**：很好！现在你观察到没，P 和 Q 分别在哪条边上运动？

**兮兮**：P 在 AD（一条边），Q 在 BC（对边）。

**我**：对，它们在对边上。现在问题是要以 P、D、Q、B 四个点构成平行四边形。你记得平行四边形的对边有什么特点？

**兮兮**：平行且相等。

**我**：没错！那这里 PD 和 QB 是一组对边，DQ 和 PB 是另一组对边。你觉得，当 P 和 Q 运动的时候，它们什么时候会"平行且相等"？

**兮兮**：速度不一样……P 慢 Q 快，所以它们可能在对边上的某个时刻会"对上"？

**我**：有感觉了！那"对上"具体是什么意思？能不能用数学语言写出来？

**兮兮**：就是……PD 的长度 = QB 的长度？因为 PD 是 P 到 D 的距离，如果 P 从 A 往 D 走，那 PD = AD - AP = 15 - t……

**我**：很好！继续，QB 呢？

**兮兮**：Q 从 C 往 B 走，QB = QC 方向……不对，题目说 Q 在 BC 上往返！所以 Q 可能从 C 往 B 走，也可能从 B 往 C 走！

**我**：👍 你发现了一个关键点！往返意味着 Q 的方向有两种可能。那你觉得需要分类讨论吗？

**兮兮**：需要！Q 往 B 走和往 C 走，是两种情况……

**我**：好，你现在自己来列方程试试，两种情况分别怎么写？

**兮兮**：（思考后）如果 Q 往 B 走，QB = 4t（从 C 到 B 距离是 BC=15，但 Q 出发点在 C……不对，是从 C 出发往返，初始时 Q 在 C！）

**我**：对，出发点在 C。所以从 C 到 B 的距离是 BC = 15 吗？

**兮兮**：等等，AD=15，BC 和 AD 是对边，也等于 15。

**我**：没错！继续。

**兮兮**：如果 Q 往 B 走，QB = 4t；如果往 C 走，Q 过了 B 之后折返，这时候……

**我**：好，你先按往 B 走的情况算，PD = 15 - t，QB = 4t，让它们相等，求出来的 t 是多少？

**兮兮**：15 - t = 4t，t = 3。但答案选项没有 3……

**我**：注意看题，两个点"同时出发，当 P 到达点 D 时停止（同时 Q 点也停止）"。P 到达 D 的时间是多久？

**兮兮**：P 走了 15，速度是 1，所以走 15 秒。但答案选项最大是 12……

**我**：说明还有别的条件我们没用上。PD 和 QB 在一条直线上，它们如果平行，需要在什么方向上？这道题不是让 PD=QB 就完了，而是 P、D、Q、B 四点构成平行四边形。你想想，平行四边形里，P 和 Q 分别在哪里？

**兮兮**：（重新画图）P 在 AD 上，D 是 AD 上的一个定点……等等，PD 不一定是对边！

**我**：👍 正是！这里 PD 是 AD 的一部分，不一定等于 QB。你再想想，平行四边形 P、D、Q、B，顶点顺序很重要——P→D→Q→B 是依次相邻的四个顶点。那 PD 和 BQ 是邻边，不是对边！

**兮兮**：啊！所以应该是 PA 和 QD？不对……

**我**：你再看看，以 P、D、Q、B 为顶点的四边形，平行四边形的对边分别是哪两条？

**兮兮**：（重新画）P 和 Q 是对角顶点！所以 PD 和 QB 是对角……不对，对角顶点连起来是对角线，不是边！

**我**：对！P 和 Q 是对角的两个顶点。那四边形的边是哪些？

**兮兮**：PD、DB、BQ、QP？但这样顺序不对……

**我**：没事，你先不管顺序，先想清楚：平行四边形里，相对的两条边平行且相等。这道题里，P、D、Q、B 要形成平行四边形，你觉得哪两条边是"相对的"？

**兮兮**：PD 和 BQ 是相对的？那它们应该平行。PD 在 AD 上，AD 是水平的，BQ 在 BC 上，BC 也水平……

**我**：没错，AD∥BC，所以 PD∥BQ 自然成立！那还需要什么条件？

**兮兮**：PD = BQ！长度相等！

**我**：好！现在回到你刚才的方程，PD = 15 - t，BQ 呢？Q 从 C 出发往 B 走，距离是……

**兮兮**：QC = 4t，但 Q 到达 B 后就折返，所以 Q 的位置要分情况……

**我**：对！这里就是关键了。你来算算两种情况。

**兮兮**：（算出两种情况）t=3 和 t=5……但还是没有 6、8、10、12 这些选项。

**我**：注意，Q 是在 BC 上往返运动，不是直线运动就结束了。Q 往返一次的距离是 2×BC = 30，所以 Q 的位置是周期性的。另外，PD 和 BQ 的关系不只是长度，还有方向——你再想想，PD = BQ 这个方程，两边是正数，但有没有可能 PD = BQ 的时候，PD 和 BQ 的方向并不满足平行四边形的要求？

**兮兮**：（重新思考）……我懂了！PD 是从 P 到 D 的向量，BQ 是从 B 到 Q 的向量，它们要平行且方向一致。如果 Q 往返的位置不对，即使长度相等也构不成平行四边形。

**我**：👍👍 正是！你看，这道题看起来是列方程，但其实分类讨论和方向判断才是真正的难点。你现在能判断出，哪些 t 值是真正满足条件的了吗？

**兮兮**：我再算算……

## 本次辅导亮点

1. ✅ **先问卡点**：开口先问"卡在哪里"，没有直接给答案
2. ✅ **逐步引导**：每个问题只给一个，画图→标条件→想关系→列方程→检验
3. ✅ **启发分类讨论**：Q往返→自然引出分类
4. ✅ **强调易错点**：长度相等≠能成平行四边形，方向也很重要
5. ✅ **最后她自己算出来**：真正的辅导是让她自己恍然大悟
