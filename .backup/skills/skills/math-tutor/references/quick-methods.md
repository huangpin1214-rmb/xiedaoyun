# 数学解题方法速查表

_来源：学科网专题 + 兮兮练习中的常见题型 + 经验总结，持续更新。_

---

## 一、动点问题

### 核心方法
1. **找等量关系列方程**——让动弹点到达某个位置时产生特定几何条件（如形成平行四边形）
2. **注意时间条件**——"同时出发、同时停止"是隐藏的时间等式
3. **平行四边形判定**——对边平行且相等，常用来列方程

### 兮兮易错点
- 速度比搞反（注意谁比谁）
- 忽略"P到达终点时Q也停止"的联动条件
- 漏讨论"P在AD上"vs"P在BC上"的不同位置

### 引导问题
- "P和Q的速度分别是多少？速度比是多少？"
- "什么时刻，四边形的四个点会满足平行四边形的条件？"
- "有没有两种不同的情况？"

## 二、最值问题

### 几何法（优先考虑）
| 方法 | 适用场景 | 核心思想 |
|------|---------|---------|
| 将军饮马 | 定点+动点，两定点在动线同侧 | 对称转移 |
| 胡不归 | 带系数的折线和最小 | 构造直角转化系数 |
| 阿氏圆 | 带系数的两线段和最小 | 找相似圆 |
| 瓜豆原理 | 主动点与从动点联动 | 旋转/位似变换 |

### 代数法
- 用函数表示目标量（长度/面积）
- 求二次函数顶点坐标
- 注意自变量取值范围

### 兮兮易错点
- 几何法想不到用"对称"
- 函数求极值忘了考虑定义域

### 引导问题
- "这个最小值，在什么位置取到？"
- "能不能把这条折线变成一条直线？"
- "有没有什么量是不变的，可以作为桥梁？"

## 三、定值问题

### 核心方法
1. **特殊位置探确定值**——把动点放到特殊位置（如中点、端点）先算出定值
2. **证明与变量无关**——推导过程中变元相互抵消

### 兮兮易错点
- 不敢取特殊值试探
- 推到一半放弃

### 引导问题
- "如果把这个动点放到最特殊的位置，会是什么情况？"
- "你算出来的结果里，哪些量会消掉？"

---

## 四、"截长补短"法

### 适用场景
几条线段需要凑在一起（和差问题）、或需要构造全等

### 操作步骤
1. 延长短的，或截取长的
2. 构造全等三角形
3. 将分散的线段转化到一处

### 例题核心思路（见专题四第5题）
- 延长 CD 使 BE = CD
- 构造 △BAE ≌ △DAC
- 把四边形面积转化为等腰直角三角形

## 五、分类讨论意识

### 必须讨论的题型
- **等腰三角形**：顶角不确定时，两底角可能相等，但顶点位置不同
- **含参不等式**：参数边界是否取等
- **动点方向**：向左还是向右、在线段上还是延长线上

### 引导口诀
> "见到等腰先想——谁是顶点？会不会有两种？"

## 六、几何辅助线常见思路

| 题目特征 | 常见辅助线 |
|---------|---------|
| 角平分线 + 平行线 | 等腰三角形 |
| 中点 | 中位线、斜边中线 |
| 垂线 | 构造直角三角形 |
| 平行四边形对角线 | 互相平分 |
| 等边三角形 | 旋转60° |
| 翻折 | 对称点连线垂直于折痕 |

## 七、兮兮高频丢分提醒

| 题型 | 常见错因 |
|------|---------|
| 平行四边形动点 | 漏情况（两种四边形位置） |
| 几何最值 | 不会用对称/将军饮马 |
| 等腰三角形分类 | 顶角漏情况 |
| 证明题 | 跳步、漏条件 |
| 运算 | k值、系数约分错误 |
