# 教育理念每日推送 Skill

## Goal

每天早上8点，生成一条针对频哥和兮兮当前备考阶段的教育理念早播报，通过飞书消息发送给频哥，结合兮兮最近的做题情况 + 最新教育研究/论文，让理念既有理论支撑又落地可执行。

## When to use

1. **定时触发**：每天早上8:00（GMT+8），cron自动触发
2. **手动触发**：频哥说"推送教育理念"或"今天的教育理念"

## Do not use

- 考试期间（中考前1个月集中备考期）暂停推送
- 不推送学术术语堆砌的长文
- 不推送空洞的"要努力"类废话
- 不推送与初二备考阶段无关的内容

## Inputs to collect

在生成推送前，检查以下信息（如无则跳过，不阻挡生成）：

1. **兮兮最近做题情况**：查看 memory/ 目录下的最近日期文件，看是否有兮兮错题或试卷相关记录
2. **MEMORY.md 中的薄弱点档案**：英语/数学/地理/物理各科当前薄弱点
3. **今日日期**：用于标题"第X天"
4. **最近教育研究**：用 Tavily 搜索一个与当前备考阶段相关的教育研究或方法论文

## Procedure

### 第一步：收集今日信息

1. 读取 `memory/YYYY-MM-DD.md`（今日）看是否有兮兮的最新动态
2. 读取 `MEMORY.md` 中的"女儿各科薄弱点"章节
3. 用 Tavily 搜索今日教育研究（关键词：中考备考、学习方法、亲子沟通、青春期教育，选一个最相关的）

### 第二步：生成早播报

按照以下四板块结构生成内容：

```
📅 第X天 | 教育理念早播报

【今日理念】一句话概括核心观点（20字以内）

【理论依据】研究/论文名称 + 一句话解读（说明这个理论解决什么问题）

【实操方法】
① 具体可执行的行动建议1
② 具体可执行的行动建议2
③ 具体可执行的行动建议3（可选）

【针对兮兮】根据最近做题情况，给一句个性化建议（可以是一道题的回顾、一个知识点的提醒）
```

### 第三步：发送飞书消息

用 message 工具发送飞书消息到频哥（open_id: ou_2ad19bb3863e71e2d0eff5cc4aeedd83）

### 第四步：记录到 memory

将今日推送内容摘要追加到当日 memory/YYYY-MM-DD.md

## Output format

飞书消息格式：Markdown，包含 emoji，每条不超过500字

## Definition of done

- [ ] 每天8:00准时发送
- [ ] 包含四板块结构
- [ ] 有理论来源（研究/论文）
- [ ] 有针对兮兮的个性化建议
- [ ] 避免学术术语堆砌
- [ ] 推送后记录到 memory
- [ ] 考试期间自动跳过

## Failure handling

- 如果 Tavily 搜索失败：跳过搜索步骤，直接基于已有信息生成
- 如果飞书发送失败：记录到 memory/ERRORS.md，稍后重试或告知频哥
- 如果某天没有兮兮的动态：基于薄弱点档案生成，不强求个性化

## Additional resources

- references/ 目录：存放参考的教育研究资料（暂无，标记为待补充）
- examples/ 目录：存放正例和反例样例
- scripts/ 目录：存放 cron 定时脚本
