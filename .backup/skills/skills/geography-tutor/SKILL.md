## 四大核心素养（教学目标）

1. **人地协调观** — 理解人类活动与自然环境的关系，树立可持续发展观念
2. **综合思维** — 从多个维度综合分析地理现象（位置/地形/气候/水文/经济）
3. **区域认知** — 认识不同尺度的区域特征（全球→大洲→中国→地区）
4. **地理实践力** — 读图、析图、用图的能力

## 教学模式

### Mode 1: 区域地理专题复习

对一个区域进行系统梳理，每个区域遵循：

```
位置（在哪）→ 自然环境（长什么样）→ 资源与经济（有什么用）→ 人地关系（怎么协调）
```

典型区域复习结构：
- **青藏高原**：高寒为整体特征；河谷农业是局部；"中华水塔"；自然保护区
- **西北地区**：干旱为核心；灌溉农业/绿洲农业；能源丰富
- **南方地区**：亚热带/热带季风；水田农业；鱼米之乡
- **北方地区**：温带季风；旱地农业；重工业基地

### Mode 2: 读图训练

针对中考必考图：
1. 中国政区图（34个省级行政区）
2. 中国地形图（三级阶梯）
3. 中国气候图（温度带/干湿区）
4. 中国河流图（长江/黄河/淮河）
5. 中国资源图（土地/水/矿产）
6. 中国农业分布图
7. 中国工业分布图
8. 世界地形图、大洲分界线图
9. 等高线地形图
10. 气候类型图

读图训练标准步骤：
```
1. 看图名（知道是什么图）
2. 看图例（知道线条/颜色代表什么）
3. 找关键地理事物（位置/走向/分布范围）
4. 归纳分布规律或特征
5. 用地理语言描述结论
```

### Mode 3: 易错易混概念辨析

中考高频混淆概念：

| 易混概念 | 区别 | 判断方法 |
|---------|------|---------|
| 地形 vs 地势 | 地形=地表形态（高原/山地）；地势=高低起伏趋势（西高东低） | 看关键词：海拔/相对高度=地形；起伏/走向=地势 |
| 纬度 vs 温度带 | 纬度决定温度带 | 北回归线内=热带/亚热带 |
| 季风区 vs 非季风区 | 夏季风能到达=季风区 | 400mm等降水量线 |
| 内流河 vs 外流河 | 最终流入海洋=外流河 | 看汇水面积 |
| 资源 vs 能源 | 资源=自然资源总称；能源=能量来源（煤/石油/天然气） | 具体区分 |
| 水田 vs 旱地 | 水田=需要灌溉；旱地=基本依赖自然降水 | 秦岭-淮河分界线 |
| 牧区 vs 农耕区 | 牧区=畜牧业为主；农耕区=种植业为主 | 降水量是核心判断标准 |

### Mode 4: 综合题解题训练

中考综合题标准解题流程：

**第一步：审题——抓住关键词**
- "分析"（找原因）vs "描述"（写现象）vs "评价"（利弊都要说）vs "提出建议"（写措施）
- 空间定位词（西北/青藏/南方）

**第二步：区域定位**
- 在中国/世界地图上确定研究区域
- 明确该区域的自然环境整体特征

**第三步：调用知识库**
- 地形+气候+水文+资源→推导出农业/工业/交通特点

**第四步：规范作答**
- 地理术语：不能用口语（如"这里雨很多"→"降水充沛"）
- 逻辑清晰：先自然后人文
- 要点化：用①②③分点

### Mode 5: 中考冲刺

针对 A 等目标生的专项训练：

**高频考点清单（按出现频率排序）：**
1. 中国四大地理分区（北方/南方/西北/青藏）—— 核心特征、界线、主导因素
2. 地形地势判断（三级阶梯、青藏高原、四大盆地、四大高原）
3. 气候类型及分布（季风气候的分布与特点）
4. 河流治理（长江/黄河的功过与治理）
5. 资源分布与调配（南水北调、西气东输、西电东送）
6. 农业地域类型（水田/旱地/河谷/绿洲/高寒牧场）
7. 人口与民族分布
8. 中国地理分界线（秦岭-淮河、400mm等降水量线）

**考前必背口诀：**
- 青藏高原：高寒日光强，草场丰富牧业旺
- 西北内陆：干旱是核心，灌溉农业靠雪山
- 南方水乡：水田农业密，长江珠江航运忙
- 北方旱作：麦浪滚滚黄土地，温带季风雨热同

## 中考 A 等标准

达到 A 等（优秀，85分以上）需要：
- 区域定位零失误
- 综合题能写出完整因果链条
- 读图题能归纳出2-3条规律
- 规范使用地理术语

## 2024年成都中考地理真题知识库

> 来源：2024年成都市初中学业水平考试地理真题（考试时间60分钟，满分100分）

### 核心考点分析（来自真题）

**一、南极科考站（结合热点）**
- 南极科考站：长城站（无极昼极夜）、中山站/昆仑站/泰山站/秦岭站（有极昼极夜，南极圈以内）
- 秦岭站2024年2月建成，是第五个科考站
- 建站方式：模块化生产+现场拼装（绿色环保）
- 底层架空目的：防积雪掩埋、抗大风（极地气候特点）
- 模块化建站目的：节省运输时间、减少极地建筑垃圾

**二、北京中轴线（传统文化+地理）**
- 北京中轴线：南北走向
- 北京城市职能：全国文化中心（不是经济中心/科技创新中心/国际交往中心）
- 北京世界遗产：目前7项，申遗成功后8项

**三、美国农业（区域专业化）**
- 乳畜带分布影响因素：气候+市场（大城市周边）
- 农业地区专业化意义：推广先进技术+发挥机械化优势（不是增加熟制/扩大用地）

**四、成都世界园艺博览会（本土热点）**
- 成都世园会：2024年4月26日-10月28日，"绿色低碳"理念
- 川西民居特点：斜坡顶、小青瓦、长出檐
- 成都气候：亚热带季风气候，水热条件好

**五、中国人口（人口与政策）**
- 人口增长最快时期：1964-1982年（改革开放前）
- 生育政策调整目的：保持适度人口增长+促进人口与社会经济均衡发展

**六、等高线地形图（读图技能）**
- 相对高度计算：海拔差
- 山体部位：鞍部（两山之间）、山脊（凸低为脊）、山谷（凸高为谷）、陡崖
- 泥石流逃生：向两侧高处跑，不能顺沟谷跑

**七、地球公转（天文地理）**
- 公转轨道位置：3月21日(春分)→6月22日(夏至)→9月23日(秋分)→12月22日(冬至)
- 天宫课堂：9月21日，运行至秋分附近

**八、成昆铁路（交通+区域发展）**
- 公益慢火车：5633/5634次，普雄至攀枝花
- 14号车厢改造：专用牲畜车厢，不收额外费用
- 目的：助力乡村振兴

### 中考常见考查方式
- 时事热点+地理知识结合（如南极建站、北京中轴线申遗、成都世园会）
- 读图题：先看图名→再看图例→找关键地理事物→归纳规律
- 综合题：先定位区域→调用自然+人文知识→用地理语言分点作答

## 2023年成都中考地理真题知识库

> 来源：2023年成都市初中学业水平考试地理真题（考试时间60分钟，满分100分）

### 核心考点分析（来自真题）

**一、南北极地区对比（结合全球气候变化热点）**
- 南北极共有特征：纬度位置高（选A）
- 南极比北极：风速更大（100m/s vs 10m/s）、降水更少（200mm vs 撒哈拉）、最冷
- 海冰变少原因：全球气候变暖（选A）
- 共同面临问题：海冰融化（全球变暖）

**二、中国人口（结合三孩政策）**
- 2022年中国人口首次负增长
- 两孩（2016）→三孩（2021）政策目的：鼓励生育、优化年龄结构
- 人口图表：看比重变化趋势（65岁以上比重上升、0-14岁比重下降）

**三、台湾与福建五缘关系**
- 海峡名称：台湾海峡（不是琼州/渤海/舟山）
- 血缘相亲体现：元宵节（不是泼水节/雪顿节/那达慕节）

**四、区域交通与农业（淄博烧烤热点）**
- 交通选线：时间+票价综合考量
- 济南至淄博农作物：冬小麦+油菜（面食为主，油料作物）

**五、大熊猫国家公园（2021年设立）**
- 分布省份：川（四川）面积最大
- 夏季防灾：滑坡、泥石流（山区）

**六、北京城市符号与职能**
- 北京符号：天安门、故宫等传统建筑
- 政治中心+文化中心（人民大会堂、国家大剧院）

**七、成都大运会（2023年7-8月）**
- 天府文化体现
- 积极影响：促进体育基础设施+提高城市知名度

**八、航天发射（酒泉+地球运动）**
- 酒泉卫星发射中心（甘肃）
- 时差原因：地球自转（时间差异）
- 昼夜长短：5月30日→夏至前→昼长夜短

**九、等高线地形图（读图技能）**
- 续2024年考查：山体部位（鞍部/山脊/山谷/陡崖）
- 泥石流逃生方向

- 北京职能：文化中心+国际交往中心

**七、冬小麦成熟期差异（纬度影响）**

**八、海峡两岸端午文化**
- 共同节日习俗：端午节赛龙舟/吃粽子
- 同根同源文化

**九、坎儿井+新疆**
- 坎儿井：新疆古老引水工程（减少蒸发）
- 塔里木盆地：绿洲农业

**六、二十四节气+地球公转**
- 立夏节气：地球运行至②段（春分→夏至）

**七、珠穆朗玛峰（8848.86米，中尼共同宣布）**
- 喜马拉雅山脉
- 尼泊尔在珠峰南麓

**八、四大名绣**
- 苏绣（江苏/鱼米之乡）湘绣（湖南）粤绣（广东）蜀绣（四川）
- 第二级阶梯城市：四川（蜀绣）、湖南（湘绣）

**九、中央储备粮库**
- 数量最多：黑龙江+吉林（东北平原，商品粮基地）
- 熟制：一年一熟（东北）

**十、黄河**
- 入海口：渤海
- 水电站众多原因：阶梯交界处落差大

> 来源：成都市2019年初中毕业会考地理试题

### 核心考点

- 我国地理位置：大部分位于北温带，太平洋西岸
- 降水量规律：从东南沿海向西北内陆递减
