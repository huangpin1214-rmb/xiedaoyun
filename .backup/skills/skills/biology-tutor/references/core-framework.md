# 初中生物核心框架

> 参考：《义务教育生物学课程标准（2022年版）》+ 中考生物会考要求

---

## 新课标四大核心素养

1. **生命观念** — 结构与功能、物质与能量、稳态与平衡、适应与进化等
2. **科学思维** — 模型与建模、演绎与推理、批判性思维
3. **探究实践** — 提出问题、做出假设、设计实验、分析数据、得出结论
4. **态度责任** — 科学态度、社会责任、生态意识、健康意识

## 七大学习主题（中考范围）

### 主题一：生物体的结构层次
- 细胞是生命活动的基本单位
- 动物细胞和植物细胞的结构与功能
- 细胞分裂、分化形成组织
- 植物体的组织、器官
- 动物体的结构层次：细胞→组织→器官→系统→动物体

### 主题二：生物与环境
- 生物圈的概念与范围
- 生态系统的组成：生产者/消费者/分解者
- 食物链和食物网
- 能量流动和物质循环
- 生物富集
- 生物圈是最大生态系统

### 主题三：生物圈中的绿色植物
- 种子萌发的条件与过程
- 植物的生长与发育
- 开花与结果（花结构、传粉、受精）
- 光合作用（场所/原料/产物/公式/意义）
- 呼吸作用（场所/原料/产物/公式/意义）
- 光合作用与呼吸作用的联系与区别
- 蒸腾作用及其意义

### 主题四：生物圈中的人
- 人体的营养：消化系统的组成与功能、三大有机物消化吸收
- 人体的呼吸：呼吸系统的组成、气体交换原理、肺通气
- 人体的循环：血液循环（体循环/肺循环）、血型与输血
- 人体的排泄：泌尿系统的组成、尿液形成过程
- 人体调节：神经系统的组成、反射与反射弧、激素调节
- 人类活动对生物圈的影响

### 主题五：动物的运动和行为
- 动物的运动：骨骼肌协作、关节结构
- 动物的行为：先天性行为（本能）vs 学习行为

### 主题六：生物的生殖、发育与遗传
- 植物的生殖：无性生殖（扦插/嫁接/压条）vs 有性生殖（种子繁殖）
- 动物的生殖：昆虫/两栖/鸟类的生殖方式
- 人的生殖：生殖系统、胚胎发育
- 遗传：染色体/DNA/基因/性状关系
- 孟德尔遗传定律
- 变异：可遗传变异 vs 不可遗传变异

### 主题七：生物的多样性
- 生物分类：界/门/纲/目/科/属/种
- 植物类群：藻类/苔藓/蕨类/种子植物
- 动物类群：无脊椎/脊椎（鱼/两栖/爬行/鸟/哺乳）
- 微生物：细菌/真菌/病毒（结构/繁殖/与人类关系）
- 生物进化：自然选择学说、人类起源

## 核心概念详解

### 光合作用（★★★★★中考高频）
**公式：** CO₂ + H₂O → 有机物 + O₂（叶绿体是场所，光是条件）
**实质：** 制造有机物，储存能量
**意义：** 地球上的"能量之源"、维持碳氧平衡

### 呼吸作用（★★★★★）
**公式：** 有机物 + O₂ → CO₂ + H₂O + 能量（线粒体是场所）
**实质：** 分解有机物，释放能量
**联系：** 光合作用为呼吸作用提供有机物和氧气；呼吸作用为光合作用提供能量

### 血液循环（★★★★）
- 体循环：左心室→主动脉→全身→上下腔静脉→右心房（动脉血→静脉血）
- 肺循环：右心室→肺动脉→肺部→肺静脉→左心房（静脉血→动脉血）
- 心脏四腔：左心房、左心室、右心房、右心室（左心室最厚，泵血到全身）
- 瓣膜作用：防止血液倒流

### 反射弧（★★★★）
五部分（必须全）：感受器→传入神经→神经中枢→传出神经→效应器
- 缩手反射：先缩手后感觉疼（低级中枢在脊髓）
- 复杂反射需要大脑皮层参与

### 遗传规律（★★★★★）
- 显性基因（A）压制隐性基因（a）
- 基因型：AA、Aa（显性）、aa（隐性）
- 生男生女：50%（每次独立）
- 概率题：列表法/分枝法
