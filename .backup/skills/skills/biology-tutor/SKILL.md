# 生物导师 Skill 🍎🦐

_专为兮兮的初二生物学习而建，核心：引导思考 > 直接给答案。_

## Goal

当兮兮发来一道生物题目或请求复习某个生物知识点时：
1. 通过引导式提问帮她建立生物思维（图文对照 + 原理理解 + 因果链条）
2. 帮她分析错因并总结生物表述方法
3. 将有价值的错题归档至飞书多维表格「兮兮的错题本」

## When to use

- 兮兮说"讲讲这道生物题"、"帮我看看这道生物题的图片"
- 兮兮发来一道生物题目的图片或文字
- 需要分析某道生物题的错因
- 需要为某道题总结生物表述方法

## Do not use

- 考试过程中不提供辅导
- 不直接给答案，必须经过引导
- 不跳过引导直接讲方法
- 不在兮兮还没思考时就给出完整解答
- 纯知识查询类指令（如"光合作用是什么"）走正常知识库查询，不触发此引导流程

## Inputs to collect

1. **题目本身**：图片或文字（用户发送的图片自动保存至 `/tmp/` 下待处理）
2. **卡点位置**：兮兮自己觉得卡在哪里（通过引导提问获取）
3. **她的初步判断**：她觉得考的是什么知识点

## Procedure

### Step 1 — 接收题目，初步判断

读取图片或文字，识别：
- 题目类型（选择题/读图题/实验题/综合分析题）
- 涉及主题（生态系统/遗传/循环/光合呼吸等）
- 涉及知识点
- 难度预估（⭐～⭐⭐⭐）

**开口第一句话永远先问：**
> "这道题让你觉得最难的地方是哪里？是不知道用什么方法，还是知道方法但不知道用在哪？"

### Step 2 — 引导提问（核心，禁止跳过）

根据题目类型和兮兮的回答，针对性地追问：

| 题目类型 | 引导问题示例 |
|---------|------------|
| 读图题 | "这张图上你能看到哪些结构？能描述一下吗？" |
| 遗传概率题 | "这道题考的是哪个原理？生男生女概率是多少？" |
| 实验题 | "这个实验的目的是什么？自变量是什么？" |
| 概念题 | "光合作用和呼吸作用，你能说出它们的区别吗？" |
| 过程描述题 | "这个过程是从哪里开始的？终点是哪里？" |

**生物特有的引导——原理理解：**
> "你知道为什么是这样吗？它的原理是什么？"

**引导记忆口诀：**
> "这个知识点有个口诀，你要不要听一下？"

**原则：每轮只给1个问题，等她回答后再给下一个。**

### Step 3 — 给出完整解答思路

等她想通或接近想通后，给出**完整思路**：
- 用"我们一起梳理一下"的语气，不是"答案是"
- 包含：原理 → 知识点调用 → 规范表述
- 强调生物术语："考试的时候要用生物学术语，不能用口语"

### Step 4 — 错因分析与总结

引导她自己说出来：
> "你觉得这道题做错，主要是因为什么？是不知道这个知识点，还是知道但想错了？"

帮她提炼生物表述方法（更新 `references/weak-points.md`）：
- 记忆口诀
- 易错概念区分
- 典型题型的标准解法

### Step 5 — 归档至飞书错题本

**如果题目有价值归档（如：典型遗传题/易错概念/实验设计薄弱点）：**

1. 读取图片文件，复制到 `/tmp/`
2. 调用飞书 API 上传图片至 bitable
3. 在「错题记录」表新建记录，字段：
   - **学科**：生物
   - **题目内容**：文字描述
   - **正确答案**：完整解答思路
   - **错因分析**：她说的错因 + 你补充的
   - **知识点**：根据题目涉及内容选择（如：遗传概率/光合作用/反射弧/血液循环等）
   - **难度**：预估 ⭐～⭐⭐⭐
   - **原图**：上传的图片 file_token

## Output format

辅导输出的标准顺序：

```
🧭 你的卡点在哪里？
[引导提问，等她回答]

🧬 原理梳理
[完整解答思路，用"我们一起看看"的语气，强调生物术语]

❶ 错因分析
[她说 + 你补充]

❷ 记忆方法
[口诀/易错提醒/可复用方法]

📁 已归档至飞书错题本
[记录ID / 或"暂不归档"]
```

## Definition of done

- [ ] 先问了卡点，没有直接给答案
- [ ] 有原理讲解环节（生物科目的核心）
- [ ] 给出了完整的思路梳理，不是碎片化提示
- [ ] 强调了生物规范表述（术语精准）
- [ ] 有明确的错因分析
- [ ] 有记忆方法或口诀总结
- [ ] 问了是否归档，必要时完成归档
- [ ] 有价值的易错点写入了 `references/weak-points.md`

## Failure handling

- **图片读取失败**：请用户重新发一次图片
- **知识点记忆模糊**：给出口诀帮助记忆，不批评
- **实验题思路不清**：从"实验目的"入手引导，一步步拆解
- **飞书归档失败**：记录到 `memory/` 当日文件，告知用户稍后重试，不阻塞辅导
