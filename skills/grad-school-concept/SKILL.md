# SKILL.md - 研究生小众概念（每日推送）

## 触发条件

**自动触发（每日定时）**：每天 22:00 推送一个"本科生不了解、研究生才懂"的小众概念

**手动触发**：频哥说"推送研究生概念"、"今天的小众概念"等

## 推送时间

- 固定时间：**22:00**（晚十点，夜深人静正好思考）
- 节假日正常推送，不因假期中断

## 内容结构（必须完整包含）

每篇推送必须包含以下7个部分，**顺序固定**：

### 1. 标题
格式：`Day N | 概念名称（英文）`
例如：`Day 47 | 伴随函子（Adjoint Functors）`

### 2. 一句话核心思想
用**一句话**说明这个概念的核心，不要提前透露名称。
格式：
```
💡 一句话理解：[这句话]
```

### 3. 第一段：故事引入
- **场景**：选择一个大多数人会熟悉的具体场景
- **人物**：1-2个有名字的角色（管理员/工程师/学徒/规划师等）
- **冲突**：发现一个看似矛盾的现象
- **字数**：200-300字
- **风格**：平实、有画面感，像在讲一个真实的故事
- **关键**：故事里不能出现概念名称或术语

### 4. 第二段：深入发现
- 在第一段场景基础上，进一步发现规律
- 引出"两种操作方向"或"两面镜子"等对偶结构
- 为第三段做铺垫，埋下伏笔
- **关键**：仍然不能出现概念名称

### 5. 第三段：升华主题
- 场景可以延伸或转移到另一个相关领域
- 揭示"这种结构不是巧合，而是某种深层规律"
- **关键**：最后一句话必须引出核心洞察，但依然不能说出概念名称

### 6. 揭晓概念
```
🎯 揭晓概念
**概念名称**（英文）
[2-3句话说明这个概念是什么，来自哪个领域]
```

### 7. 故事与概念对照表（核心结构）
用表格形式，清晰说明故事每个元素对应数学/理论含义：

| 故事情节 | 数学对应 |
|---------|---------|
| 第一个对照项 | 对应的概念要素 |
| 第二个对照项 | 对应的概念要素 |
| ... | ... |

**这一部分至关重要**，是让非专业读者"恍然大悟"的关键。

### 8. 更具体的例子
给一个概念的实际例子（如果概念来自数学/计算机/芯片领域，优先用这些领域的例子；如果没有，可以用日常例子）。

### 9. 为什么这个概念"高级"？
分2-3点说明这个概念为什么值得理解，每点一句话。
格式：
```
我认为它高级在三个地方：
1. [第一点]
2. [第二点]
3. [第三点]
```

## 概念选择标准

**优先选择**：
- 有"反直觉"或"原来如此"的惊喜感
- 能连接不同领域（数学/计算机/物理/工程/日常）
- 有具体的例子可以对照
- 适合用"两-sided"结构讲故事（构造vs遗忘、自由vs约束、压缩vs生成）

**已使用过的概念（至少间隔30天）**：
- 伴随函子（Adjoint Functors）
- 对偶性（Duality）
- 同调（Homology）
- 上同调（Cohomology）
- 函子性（Functoriality）

**概念来源优先级**：
1. 范畴论/代数拓扑（结构与关系）
2. 计算理论/编程语言（语义与证明）
3. 优化与控制理论
4. 信号处理与信息论
5. 统计学习理论

## 质量检查清单

发布前必须逐项确认：

- [ ] 三段故事场景具体、有画面感
- [ ] 三段故事中未出现概念名称或术语
- [ ] 概念揭晓时机恰当（读者应已能猜到）
- [ ] 对照表完整、对应关系准确
- [ ] 一句话核心思想简洁有力
- [ ] "为什么高级"部分有独到见解，不是泛泛而谈
- [ ] 总字数在800-1200字之间
- [ ] 无专业术语堆砌，非专业读者能看懂70%以上

## 输出格式

直接输出完整推送内容，不要加额外说明。用飞书消息格式（纯文本）。

## 概念库管理

### 当前概念库（15个，分布在6个领域）

脚本 `scripts/grad-school-concept-daily.sh` 中预定义概念库，每次从**未使用或已超过30天**的概念中随机选。

**入库标准**：
- 有"反直觉"或"原来如此"的惊喜感
- 能连接不同领域（跨学科价值高）
- 研究生及以上才会系统学到（非通识）
- 可以用"两面结构"讲出故事（构造vs遗忘、自由vs约束、压缩vs生成等）

**概念库领域分布**：

| 领域 | 概念数 | 示例 |
|------|-------|------|
| 认知/思维 | ~10 | 幸存者偏差、贝叶斯推理、确认偏误 |
| 科技/工程 | ~10 | 库梅尔定律、涌现、路径依赖 |
| 经济/金融 | ~8 | 能力圈、规模效应、机会成本 |
| 跨学科方法论 | ~8 | 信息熵、归纳偏置、双盲实验 |
| 物理/工程思维 | ~6 | 熵增原理、最小作用量原理 |
| 哲学/社会 | ~6 | 黑天鹅、反脆弱、林迪效应 |

### 每月概念库扩充流程

**触发时间**：每月第三个周六 10:00（周末频哥休息，可以想一下有没有值得推荐的概念）

**流程**：
1. 我主动搜索/阅读，筛选出符合入库标准的新概念（3-5个）
2. 把候选概念和筛选理由整理成清单，通过飞书发给频哥
3. 频哥确认后，我来更新脚本里的概念库
4. 更新 `memory/grad-school-concepts.md` 的"概念候选池"章节

## 脚本

- 推送脚本：`scripts/grad-school-concept-daily.sh`
- 扩充脚本：`scripts/grad-school-concept-expand.sh`（每月自动调用）
- Crontab：`0 22 * * *`（每日推送）
- 月扩：Crontab 第六个字段留空，默认每月第三个周六 10:00 由 heartbeat 触发
