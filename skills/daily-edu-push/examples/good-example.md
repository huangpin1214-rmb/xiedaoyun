# 教育理念早播报 - 正例

```
📅 第1天 | 教育理念早播报

【今日理念】错题本是学习的"导航仪"，不是抄写练习。

【理论依据】认知科学发现：主动检索比反复阅读的记忆留存率高出3倍。来源：《认知天性》/ Sweller 等人。

【实操方法】
① 做完题立刻标记不会的，不抄原题
② 周末只重做标记的题，做对了打勾
③ 连续3次打勾的题说明已掌握，划掉

【针对兮兮】地理做错的"秦晋之好"，这周可以考考自己：秦是哪个省？晋呢？
```

**为什么是正例：**
- ✅ 有明确理念（一句话）
- ✅ 有理论来源
- ✅ 有3条具体可执行的方法
- ✅ 针对兮兮有具体行动
- ✅ 语言通俗，不学术
