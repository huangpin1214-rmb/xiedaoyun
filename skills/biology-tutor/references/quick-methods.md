## 易错易混概念辨析

| 易混概念 | 区别 | 记忆方法 |
|---------|------|---------|
| 动脉 vs 静脉 | 送血离/回心脏 | "离"字像动脉的"脉" |
| 动脉血 vs 静脉血 | 含氧高低/颜色 | 鲜红=动脉；暗红=静脉 |
| 反射 vs 反应 | 反射有反射弧结构 | 缩手反射先缩后疼 |
| 抗原 vs 抗体 | 抗原=外来物；抗体=自身产生 | 抗体在血清中 |
| 光合作用 vs 呼吸作用 | 白天制造/时时刻刻分解 | 记住公式对比 |
| 有性生殖 vs 无性生殖 | 有无配子结合 | 有种子/受精卵=有性 |
| 显性基因 vs 隐性基因 | 显性压制隐性 | AA和Aa都显性 |
| 细胞分裂 vs 细胞分化 | 数量↑ vs 种类↑ | 分裂=复制；分化=变成专业工种 |
| 蒸腾作用 vs 光合速率 | 失水 vs 气体交换 | 蒸腾是水叶片跑出去 |
| 自然选择 vs 用进废退 | 适者生存 vs 拉马克 | 自然选择是对的 |
| 生态系统 vs 生物圈 | 小范围 vs 最大 | 生物圈包含所有生态系统 |

## 实验答题套路（中考必考）

### 基本步骤
```
1. 取材：选取材料的原则（随机分组、相同条件）
2. 条件控制：自变量/因变量/无关变量
3. 观察记录：定时/定量记录
4. 分析结果：数据处理/曲线绘制
5. 得出结论：验证或否定假设
```

### 对照实验设计
- 实验组：施加自变量
- 对照组：不施加自变量（或施加已知量）
- 原则：单一变量原则（其他条件相同）

### 绿叶在光下制造有机物实验
1. 暗处理：消耗叶片中原有有机物（饥饿处理）
2. 遮光对照：叶片一半遮光一半不遮
3. 酒精脱色：去掉叶绿素（叶片变黄白）
4. 碘液染色：遮光部分不变蓝（没制造有机物）；见光部分变蓝（制造了淀粉）

### 探究种子萌发条件
- 对照组：适宜水分、温度、空气
- 实验组：逐一改变其中一个条件
- 结论：种子萌发需要水、空气、适宜温度

## 读图答题步骤

```
1. 识别图的类型（结构图/过程图/曲线图）
2. 找到图中标注的关键结构/文字
3. 理解图的含义（这个结构做什么）
4. 运用生物学知识分析
5. 用规范语言表述答案
```

---

## 综合题答题规范

- **问原因**：先结论后理由（"因此/所以…"开头）
- **问结论**：直接写出发现
- **问建议**：结合材料提1-2条可行措施
- **避免口语**：用生物学术语（如"光合作用"而非"光合"）

---

## 考前必背口诀

- 光合：光合作有光才，CO₂进O₂出，储存能量在有机物
- 呼吸：呼吸不管有光无光，O₂进CO₂出，释放能量在有机物
- 消化：口腔嚼胃搅，小肠是主战场，胰胆配合来帮忙
- 循环：动脉送血离心脏，静脉回心不能忘，毛细血管来交换
- 反射弧：感入神中出效应（五部分不能少）
