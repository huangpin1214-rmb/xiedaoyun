# 地理解题方法速查表

---

## 读图训练标准步骤（中考必考）

```
1. 看图名（知道是什么图）
2. 看图例（知道线条/颜色代表什么）
3. 找关键地理事物（位置/走向/分布范围）
4. 归纳分布规律或特征
5. 用地理语言描述结论
```

## 综合题答题模板

### 描述类
"从___到___，___（地理事物）逐渐___（变化），主要受___因素影响。"

### 分析类
"___（地理现象）的主要原因有：①___；②___；③___。"

### 影响类
"有利影响：①___；②___。不利影响：①___；②___。"

### 建议类
"可以采取以下措施：①加强___；②建设___；③提高___意识。"

## 兮兮高频丢分提醒

| 题型 | 常见错因 |
|------|---------|
| 等高线地形图 | 山脊山谷判断混淆（凸低为脊，凸高为谷） |
| 泥石流逃生 | 顺沟谷跑（正确：向两侧高处跑） |
| 地形 vs 地势 | 混用术语 |
| 区域定位 | 青藏/西北/南方特征混淆 |
| 气候类型 | 温带季风/亚热带季风分布范围搞混 |
| 河流治理 | 长江/黄河的治理措施张冠李戴 |
| 地球运动 | 季节和昼夜判断搞反 |

## 关键分界线

| 分界线 | 地理意义 |
|--------|---------|
| 秦岭-淮河 | 1月0℃等温线、800mm等降水量线、亚热带与暖温带分界线 |
| 400mm等降水量线 | 季风区与非季风区分界线、农耕区与畜牧区分界线 |
| 黑河-腾冲一线 | 胡焕庸线（人口分布） |
| 北回归线 | 热带与亚热带分界线 |
| 青藏高原边缘 | 地势第一二级阶梯分界线 |
