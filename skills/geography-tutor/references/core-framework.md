# 初中地理核心框架

> 参考：《义务教育地理课程标准（2022年版）》+ 中考地理考试要求

---

## 初中地理知识体系（五大主题）

**主题一：地球在家园**
- 地球的形状、大小、运动（自转/公转）
- 地球仪、经纬线、经纬度
- 地图（三要素：比例尺/方向/图例）
- 陆地与海洋（大洲、大洋、岛屿、半岛）
- 天气与气候

**主题二：认识世界**
- 大洲和大洋的名称、位置、分界线
- 世界地形、气候分布
- 区域地理：亚洲、欧洲、非洲、美洲等
- 发达国家与发展中国家
- 国际合作

**主题三：认识中国**
- 疆域与行政区划
- 人口与民族
- 自然环境：地形、气候、水文
- 自然资源：土地资源、水资源、矿产资源
- 经济发展：农业、工业、交通
- 四大地区：北方、南方、西北、青藏

**主题四：地理工具与地理实践**
- 地图的阅读与使用
- 等高线地形图
- 地理信息技术（GIS、GPS、RS）
- 野外考察与调查方法

**主题五：跨学科主题学习**
- 地理与其他学科的结合
- 综合性问题分析

---

## 四大核心素养（教学目标）

1. **人地协调观** — 理解人类活动与自然环境的关系，树立可持续发展观念
2. **综合思维** — 从多个维度综合分析地理现象（位置/地形/气候/水文/经济）
3. **区域认知** — 认识不同尺度的区域特征（全球→大洲→中国→地区）
4. **地理实践力** — 读图、析图、用图的能力

## 区域地理专题复习结构

对一个区域进行系统梳理，每个区域遵循：

```
位置（在哪）→ 自然环境（长什么样）→ 资源与经济（有什么用）→ 人地关系（怎么协调）
```

**青藏高原**：高寒为整体特征；河谷农业是局部；"中华水塔"；自然保护区
**西北地区**：干旱为核心；灌溉农业/绿洲农业；能源丰富
**南方地区**：亚热带/热带季风；水田农业；鱼米之乡
**北方地区**：温带季风；旱地农业；重工业基地

## 易错易混概念辨析

| 易混概念 | 区别 | 判断方法 |
|---------|------|---------|
| 地形 vs 地势 | 地形=地表形态（高原/山地）；地势=高低起伏趋势（西高东低） | 看关键词：海拔/相对高度=地形；起伏/走向=地势 |
| 纬度 vs 温度带 | 纬度决定温度带 | 北回归线内=热带/亚热带 |
| 季风区 vs 非季风区 | 夏季风能到达=季风区 | 400mm等降水量线 |
| 内流河 vs 外流河 | 最终流入海洋=外流河 | 看汇水面积 |
| 资源 vs 能源 | 资源=自然资源总称；能源=能量来源（煤/石油/天然气） | 具体区分 |
| 水田 vs 旱地 | 水田=需要灌溉；旱地=基本依赖自然降水 | 秦岭-淮河分界线 |
| 牧区 vs 农耕区 | 牧区=畜牧业为主；农耕区=种植业为主 | 降水量是核心判断标准 |

## 综合题标准解题流程

**第一步：审题——抓住关键词**
- "分析"（找原因）vs "描述"（写现象）vs "评价"（利弊都要说）vs "提出建议"（写措施）
- 空间定位词（西北/青藏/南方）

**第二步：区域定位**
- 在中国/世界地图上确定研究区域
- 明确该区域的自然环境整体特征

**第三步：调用知识库**
- 地形+气候+水文+资源→推导出农业/工业/交通特点

**第四步：规范作答**
- 地理术语：不能用口语（如"这里雨很多"→"降水充沛"）
- 逻辑清晰：先自然后人文
- 要点化：用①②③分点

---

## 中考 A 等标准

达到 A 等（优秀，85分以上）需要：
- 区域定位零失误
- 综合题能写出完整因果链条
- 读图题能归纳出2-3条规律
- 规范使用地理术语
