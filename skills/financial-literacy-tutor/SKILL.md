# Goal

每周为频哥生成一份面向兮兮（14岁/初二）的财商对话手册，通过日常场景渗透，让兮兮在真实的花钱/管钱决策中理解财商概念。

三年学习路径框架：
- **第一年（现在 ~ 初三）：** 打地基 — 记账、区分Needs/Wants、储蓄习惯、靠自己做成一件事
- **第二年（高一~高二）：** 理解钱的运转 — 复利、通胀、信用卡/贷款基础、风险意识
- **第三年（高三~大学前）：** 投资启蒙 — 股票/基金/债券、分散风险、创业/商业思维、看懂基础财报

每周从对应年份的阶段主题库中选取，按顺序推进，不跳阶段。

## When to Use

频哥说以下任一触发词时：
- "这周想跟兮兮聊一个财商话题"
- "兮兮这周学什么财商主题"
- "给我个财商教学话题"
- "兮兮财商"

---

## Do Not Use

以下情况不触发本Skill：
- 兮兮在考试周/考试期间
- 兮兮情绪不好或状态不佳
- 频哥要的不是对话手册而是其他内容（理财建议、具体投资决策等）
- 用于其他目的（比如直接给兮兮上课）

## Inputs to Collect

启动时收集（如未提供则使用默认值）：

| 信息 | 默认值 | 说明 |
|------|--------|------|
| 兮兮年级 | 初二（14岁） | 影响讲解难度 |
| 当前学习阶段 | 第一年：打地基 | 根据三年路径推算 |
| 兮兮兴趣锚点 | 周深（音乐偶像） | 用于比喻和故事连接 |
| 之前学过的财商主题 | 无记录，从头开始 | 已学主题不重复 |
| 兮兮当前可支配资金情况 | 未知（可追问频哥） | 影响场景设计 |

## Procedure

### Step 1 — 确定本周主题

从当前阶段的未学主题列表中选取第一个，按顺序推进：

**第一年（打地基）主题顺序：**
1. 区分"需要"和"想要"（Needs vs Wants）
2. 记账：你的钱花去哪里了
3. 储蓄习惯：先存后花
4. 做成一件事：赚钱是什么感觉
5. 压岁钱怎么管
6. 学校便利店经济学
7. 比价与性价比
8. 什么是"划算"

**第二年主题顺序：**
9. 复利：时间的力量
10. 通胀：钱会慢慢变薄
11. 信用卡是什么
12. 贷款：借钱要还的代价
13. 风险意识：没有稳赚不赔
14. 什么是"投资"
15. 储蓄 vs 投资
16. 什么是保险

**第三年主题顺序：**
17. 股票是什么
18. 基金是什么
19. 债券是什么
20. 分散风险
21. 创业思维：解决的问题值多少钱
22. 什么是好生意
23. 看懂一张最简单的财报
24. 总结与综合应验

### Step 2 — 生成对话手册

按以下结构输出（控制在500字以内，频哥3分钟能看完）：

```
## 本周主题：[主题名称]

### 核心概念
兮兮需要理解什么（用1-2句话，贴近她的生活）

### 为什么这个话题重要
用周深的比喻/故事，或者贴近她生活的场景切入（1-2句）

### 对话引导（3-5轮）
用"问→引导思路→等待回答"的格式
每轮控制在40字以内
不要直接给答案，要让她自己说出来

### 本周场景建议
在什么真实场景里引入这个话题（1个具体场景）

### 本周小任务
兮兮这周可以立刻做的1个具体行动（可操作、可验证）
```

### Step 3 — 确认完成标准

输出后确认：
- [ ] 兮兮能用自己的话复述核心概念
- [ ] 频哥知道怎么在实际场景里引入话题
- [ ] 有一个本周可以操作的具体行动建议
- [ ] 兮兮有真实的决策机会（哪怕很小）
- [ ] 话题在生活中留下了痕迹

---

## Output Format

纯文本输出，包含：
- 本周主题标题
- 核心概念（1-2句）
- 对话引导（3-5轮）
- 场景建议（1个）
- 本周小任务（1个）

不使用表格、markdown复杂格式，用自然段落+要点列表即可。

---

## Definition of Done

每周对话手册完成后，以下标准均可打勾：
- [ ] 兮兮理解了本周的核心概念（能用自己的话复述）
- [ ] 频哥知道了怎么在实际场景里引入这个话题
- [ ] 有一个本周可以操作的具体行动建议
- [ ] 兮兮有真实的决策机会（哪怕是很小的花钱决定）
- [ ] 这个话题在生活中留下了痕迹（过几天能想起聊过什么）

---

## Failure Handling

| 情况 | 处理方式 |
|------|----------|
| 兮兮不配合/不感兴趣 | 换更贴近她生活的场景，或暂停一周，不强求 |
| 频哥说"这周不合适" | 跳过本周主题，下周再试 |
| 兮兮的回答偏离主题 | 用追问把她引回主题，不直接纠正 |
| 触发时兮兮在考试期 | 告知"考试期间暂停财商话题，考后再继续" |
